# Family Tree Generator

## Backend
- NestJS
- TypeScript
- PostgreSQL
- TypeORM
- class-validator
- class-transformer

## Frontend
- Next.js App Router
- TypeScript
- Tailwind CSS
- Lucide React
- Axios

## Rules
- Never use Prisma.
- Never introduce another ORM.
- Use TypeORM migrations.
- Use DTOs for API input.
- Keep controllers thin.
- Put business logic in services.
- Keep frontend components modular.
- Do not modify unrelated files.
- Do not install unnecessary dependencies.
- Do not build multiple phases without explicit instruction.
- Explain changes after each task.
